# Udemy Clone Project

A responsive web application that replicates core Udemy functionality with course search, filtering, and browsing capabilities.

## 🌟 Features

- **Course Search**: Real-time search functionality to find courses by title
- **Advanced Filtering**: Filter courses by:
  - Quizzes and assessments
  - Coding exercises and challenges
  - Practice tests
  - Course ratings
  - Skill levels
- **Course Catalog**: Browse recommended, trending, and featured courses
- **Pagination**: Navigate through search results with previous/next buttons
- **Course Details**: View comprehensive course information including ratings, instructor details, and curriculum

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling with Flexbox and responsive design
- **JavaScript (ES6+)** - Modern JavaScript with modules
- **DOM Manipulation** - Dynamic content rendering
